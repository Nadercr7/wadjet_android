REAL ENGINEERING

What Broke (and how we fixed it)

BUG

Auth token leak

AuthInterceptor sent Bearer tokens to every request. Wikipedia's image CDN was receiving our auth headers. Bad.

FIX

Scope to API base URL

Check the request URL against base before attaching tokens. External requests skip auth entirely.

CRASH

Chat duplicate IDs

IDs used sessionId_timestamp. Two messages in the same millisecond = collision. Crash on history load.

FIX

Add array index to ID

New format: sessionId_index_timestamp. Index guarantees uniqueness within a batch.

DESIGN

18-module dependency graph

Feature modules need core but can't see each other. Cross-feature navigation without direct dependencies.

FIX

Domain contracts + type-safe nav

Domain layer defines contracts. Compose Nav 2.8+ for routes. Hilt scoping enforces boundaries.
